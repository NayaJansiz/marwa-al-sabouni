# Marwa Al-Sabouni — Bilingual Portfolio

An editorial portfolio for architect and author Marwa Al-Sabouni, in English and Arabic.

## Creative direction
The visual direction is informed by the two references supplied for this project:
- [SML Architects](https://www.sml-architects.com/) — architectural project storytelling, image-led layouts and editorial restraint.
- [Elif Şafak](https://www.elifsafak.com.tr/home) — a personal, author-led identity and clear presentation of books, public appearances and media.

The site will interpret these references in an original design. It will not copy their layouts or branding.

## Sections
- Projects
- Publications: Books and Articles
- Participations: Upcoming and Past Talks
- Publicity: Interviews and Reviews
- About
- Contact

## Stack
- Astro + TypeScript
- Static output, intended for Cloudflare Pages
- Sveltia CMS planned for content management
- English and Arabic with LTR/RTL support

## Local development
```sh
npm install
npm run dev
npm run check
npm run build
```

## Content integrity
The current project and architecture imagery are visual placeholders only. Do not present them as Marwa's real work. Do not invent biography, projects, publications, talks, interviews, reviews, credentials or contact details. Replace placeholders only with materials approved by Marwa.

## Deployment target
Cloudflare Pages. Build command: `npm run build`; output directory: `dist`.
